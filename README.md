# Remember Finance

**[Open Remember Finance](https://finance-remember.yogurt-co.chatgpt.site/)** — start a daily finance learning session.

A guided study companion to Robert Shiller’s introductory [Financial Markets course](https://www.coursera.org/learn/financial-markets-global/). Forty-five guided lessons cover all 140 concepts and 28 calculation families. The October 20, 2026 readability pass expands the explanations into connected sections rather than compact definitions. Financial rules and historical notes retain their dated source snapshot, checked October 11, 2026. Recording dates do not organize the course.

## Daily use

1. Open **Today** and press **Start lesson** or **Continue lesson**.
2. Read the situation and the explanation in short sections. Each lesson identifies the units and period before the calculation. Numerical examples show their assumptions, steps, result units and what the result means.
3. Try one application question, or choose **Walk me through it**.
4. Choose **Clear** or **Needs another look**, then stop for the day or continue if you want.

**Lessons** browses the course by chapter. **Reference** searches the full concept and formula library. **Explain key terms** and **Explain formula terms** provide short definitions on demand. Further detail and additional numerical variations are optional. There is no forced immediate repetition in the main lesson flow.

The first three lessons retain the familiar bond story in a shorter format. The price explorer now shows the discounting calculation for every slider value. Each later lesson introduces a concrete situation and explains unfamiliar words as they appear. Reviews show the situation, units and first explanatory section; the remaining explanation and worked example are available in a collapsed refresher.

## Explanations and readability

The teaching text uses short connected sections with meaningful headings. It distinguishes a dollar gain from a percentage return and states the time period. Annual rates, monthly payments, dollars per share, percentage-point changes and unitless ratios are identified separately. The 145 topic glossary definitions and 12 basic definitions explain vocabulary in everyday language. All 140 Reference explanations and the 12 chapter introductions use the same approach. The historical connections retain their sources while explaining unfamiliar ideas inline.

`reference-explanations.txt` is the authored source for Reference answers and explanations; `build_content.py` validates complete coverage and keeps correct answer choices aligned when regenerating content. Lesson sections in `lesson-content.js` are the authored teaching source. Their combined `teaching` field is derived for term matching. Preserve IDs when editing prose so saved progress still matches.

## Numbers and formulas

Worked examples use hypothetical teaching inputs, clearly identified as assumptions rather than current market quotes. All 28 calculation templates also identify the output units, period, and meaning of the result. They expose input labels and intermediate working: decimal conversion, units, cash-flow timing, principal/coupon distinctions and rounding where applicable. Results are calculated at full precision before display rounding. Fixed bond examples separately show coupon and principal construction and each discounted payment.

Dates, implementation timing and standard contractual conventions are identified as source or definition facts rather than calculated amounts. Links to primary sources remain in the related-concept reference. Simplified models and their limits are stated in the lessons and reference explanations.

## In-app calculator

Open **Calculator** beside a formula reference, worked example or numeric exercise. Type an expression or use the keypad; press **=** or Enter. Basic arithmetic, parentheses, powers, square roots and continuous-growth `exp(...)` calculations are supported. `%` consistently means divide by 100: `1000 × 5%` gives `50`. Parentheses and normal arithmetic precedence apply. `50 ÷ (1 + 6%)^2` discounts a payment without leaving the lesson.

Numeric exercises provide **Use result in my answer**, which fills the answer without submitting or grading it. A nearby reminder explains the required units: a decimal return must be multiplied by 100 when the answer expects a percentage number. Clear and backspace are available. Opening the calculator does not reveal a problem’s solution or change ratings. Its scratch expression stays in memory across panel rerenders for the same problem, but is not part of saved progress or backups and resets on page reload.

The calculator runs locally with no added dependencies and is included in offline and standalone builds. Its parser accepts arithmetic data without executing JavaScript. It displays up to 15 significant digits and reports incomplete expressions, division by zero and invalid real-number results. It is an arithmetic scratch tool, not an automatic bond, mortgage or financial-planning calculator.

## Retention and progress

A clear lesson initially schedules a review in three days; later intervals roughly double, up to sixty days. Needs another look schedules tomorrow. These are practical heuristics, not a validated personal memory model or a guarantee of mastery. Due reviews include a context reminder and one application, with the fuller lesson available on request. [Research on practice testing and distributed practice](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html) informed the retention design.

The home page chooses an active lesson first, then a due review, then an unexplored lesson. All chapters stay available for manual browsing. Completion records practice and the learner’s confidence, rather than certifying understanding.

Earlier card practice remains under **Settings → Optional card-practice preferences**. Its card IDs, notes, review history and storage key are preserved. It retains its own daily limits and grading behavior; it is not the main learning path.

## Your data

Lesson progress uses `finance-guided-lessons-v1`; earlier card progress still uses `finance-remember-v1`. Completed original bond trials are recognized from `finance-bond-trials-v1`. A partly explored trial resumes as its new compact lesson. Original trial records remain untouched.

Settings exports both card and lesson progress in a validated JSON backup. Import requires an explicit replacement action after validation. Older backups without lesson data leave current lesson progress intact. Raw recovery downloads include all three original storage values. There is no account synchronization. Different browsers, devices, domains and local ports have separate storage; use export/import to transfer progress.

After an initial successful load and service-worker installation, the hosted app works offline. Installation is available from the header when the browser supports it, with platform-specific instructions otherwise. No analytics, account backend or automatic text-grading service is included.

## Run locally

```sh
npm start
```

Open **http://localhost:8766/#today**. To select another port:

```sh
npm start -- --port 9000
```

Stop the server with Ctrl+C. Changing ports changes the browser storage origin.

For a server-free preview, run `python3 build_standalone.py` and open `standalone/guided-finance.html`. `finance-remember.html` is the same full app; `bond-trials.html` opens the bond chapter for compatibility. Browser behavior for local-file storage can differ, so keep backups.

## Maintain and verify

```sh
npm ci
python3 build_content.py
npm test
```

`build_content.py` writes the existing concept reference. `dist/lesson-content.js` contains the authored lesson groups and short glossary. `guided-progress.js` manages lesson persistence and trial migration; `guided-ui.js` renders the main flow. `connections.js` contains the optional researched enrichment and its source links. `calculations.js` supplies varying problems, explicit assumptions and worked steps. `calculator.js` supplies the arithmetic parser and inline calculator. The static hosting directory remains `dist/`.

Preserve concept and lesson IDs when correcting wording. Add newly covered concepts to a lesson group; coverage checks verify that every concept is included exactly once and every calculation family is available. Bump the service-worker cache for published changes. The standalone build embeds all modules and content without runtime dependencies.

Automated checks cover numeric benchmarks, parameterized calculations, full curriculum coverage, migration, review scheduling, backup validation, storage failures, all 45 lesson flows, optional calculations and preservation of the earlier review mode. Browser visual QA is unavailable in this session; responsive layout is implemented but not visually verified here.
